# 🧠 Braille Decryption Game

A fast-paced browser game where players decode Braille symbols before time runs out.  
Test your pattern recognition, reaction speed, and memory while maintaining your streak.

---

## 🎮 Features

- 🔤 Random Braille symbol challenges
- ⏱️ Countdown timer with animated timer bar
- 🔥 Streak tracking system
- 🔒 Encrypted hacker-style overlay effect
- 💀 Game over screen with replay option
- 📱 Responsive layout for desktop and mobile

## 🧩 Game Mechanics

1. A target Braille symbol appears at the top.
2. Players must click the matching symbol from the grid.
3. Correct answers increase the streak.
4. Wrong answers or time expiration trigger game over.
5. The encrypted overlay adds immersive cyber-style feedback.
